[![Code of Conduct](https://img.shields.io/badge/Contributor%20Covenant-2.1-4baaaa.svg)](CODE_OF_CONDUCT.md)

**AuraCare Menstrual App** is a privacy-first Flutter mobile application and web portal designed for cycle phase tracking, ovulation prediction, symptom logging, and reproductive wellness insights.

---

## ✨ Features

- 🌸 **Cycle Phase Visualizer**: Interactive wheel displaying Menstrual, Follicular, Ovulatory, and Luteal phases.
- 📝 **Daily Symptom & Mood Logger**: Track cramps, energy levels, mood changes, and flow intensity.
- 🔒 **Privacy-First Storage**: Local data encryption ensuring health privacy.
- 📱 **Multi-Platform Flutter Core**: Built for Android, iOS, and Web.
- 🌐 **Interactive Web Portal**: Standalone browser tracker [`index.html`](index.html).

---

## 🚀 Quick Start

### 1. Launch Web Tracker
Open [`index.html`](index.html) in any modern browser.

### 2. Run Flutter App
```bash
flutter pub get
flutter run
```
